# مطابقة فواتير الموردين — E-Invoice Validation

برنامج عربي محلي يطابق فواتير الموردين الإلكترونية (منظومة الفاتورة الإلكترونية المصرية ETA) مع عروض الأسعار المعتمدة شهرياً، ويحسب فروق الكمية والسعر والوحدة، والإشعارات الدائنة، والخصم والإضافة، وصافي المستحق لكل ظرف مورد.

## التحميل والتشغيل (للمستخدم)
1. من صفحة **Releases** في المستودع نزّل ملف `EInvoiceValidation-<الإصدار>.zip` (فيه Node محمول، لا يحتاج تثبيت أي شيء).
2. فك الضغط في أي مجلد، ثم شغّل `Install-Shortcut.vbs` مرة واحدة لعمل اختصار على سطح المكتب.
3. افتح البرنامج من الاختصار، واعمل **الإعداد الأول** (حساب المدير).
4. التفاصيل في `tools/release/دليل الاستخدام.md`.

البرنامج يعمل على جهازك فقط. البيانات تُحفظ مشفرة (AES-256) في مجلد خارج مجلد البرنامج، ولا تُرسل لأي مكان. مفاتيح الذكاء الاصطناعي وبيانات ربط الضرائب يدخلها كل مستخدم بنفسه وتُحفظ مشفرة عنده.

البرنامج **يقرأ فقط** من منظومة الضرائب؛ لا يرسل ولا يلغي ولا يرفض أي فاتورة.

## للمطورين
- المتطلبات: Node.js 20 أو أحدث.
- التشغيل: `Start-EInvoice.vbs` (يفتح من الاختصار فقط؛ الدخول من المتصفح مباشرة مرفوض عمداً).
- الاختبارات: `node --test` (خادم + هجوم)، واختبارات الواجهة: `node tests/start-ui-test-server.js`.
- بناء حزمة التوزيع: ضع `node.exe` محمول في مجلد `runtime/` ثم `node tools/build-release.js` — الناتج في `dist/`.

| المسار | المحتوى |
|---|---|
| `server.js`, `server/` | الخادم المحلي: الدخول والجلسات والصلاحيات والتخزين المشفر ووسيط ETA والذكاء الاصطناعي |
| `app/` | الواجهة (عميل رفيع)؛ المكتبات في `app/vendor` بدون CDN |
| `tests/` | اختبارات الخادم والهجوم والواجهة (منظومة وذكاء اصطناعي وهميان) |
| `tools/` | سكربت بناء الحزمة وملفات التوزيع |
